VISMAYAS BOREDOM BREAKER — PWA

This is a Progressive Web App package.
Files:
- index.html: app
- manifest.json: installable-app metadata
- sw.js: offline cache
- icon.svg: app icon

IMPORTANT:
A PWA must be hosted over HTTPS for browser installation/service-worker features to work reliably.
After hosting, open the HTTPS address on the phone and use the browser's "Add to Home screen" / "Install app" option.
The QR code should point to that HTTPS address.

Creator Mode is included in the app so you can prepare all 30 days before giving it to Vismaya.
